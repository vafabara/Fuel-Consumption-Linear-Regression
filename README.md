# Fuel Consumption Linear Regression

A beginner machine learning project using the **Fuel Consumption dataset** to explore the relationship between vehicle features and CO₂ emissions.

## What I Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## What I Did

* Loaded and explored the dataset
* Visualized the data
* Split data into Train/Test sets
* Built Linear Regression models
* Compared `ENGINESIZE` and `FUELCONSUMPTION_COMB`
* Evaluated the models using **R²**

## Run

```bash
python main.py
```
